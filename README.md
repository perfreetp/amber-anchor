# 草坪养护 · 三维布置编辑器

面向草坪养护公司方案组的喷头与苗木三维布置工具。SolidJS + three.js（优先 WebGPURenderer，自动回退 WebGL）。

## 运行

```bash
npm install
npm run dev      # 开发
npm run build    # 构建到 dist/
```

## 功能

**编辑器**
- 场地边界：导入 JSON / GeoJSON 边界文件，或在场景中手绘边界点闭合后挤出地面
- 素材库拖放：旋转喷头、散射喷头、电磁阀、苗木、灯具、长椅；落下贴地，靠近边界自动吸附边界线
- 选中物体出现移动 / 旋转 / 缩放三种手柄（快捷键 W / E / R，Delete 删除）
- 拖动与落位时做占位圆碰撞检测：重叠物体标红，且不允许落位（自动回退）
- 喷头显示喷洒覆盖扇形，射程 / 角度滑块实时更新；多喷头覆盖区域因半透明叠加自然加深
- 相机：斜视（轨道）、俯视、第一人称漫游（点击锁定鼠标，WASD 移动，Esc 退出）
- 导出：俯视正交图 PNG（带编号圆点与坐标表）、布置坐标 CSV
- 物料清单：按类别 + 型号自动统计数量与金额

**后台管理**
- 素材库：运营配置各素材的型号、单价、占位半径、喷洒参数
- 方案审查：项目提交审查 → 通过 / 驳回（附意见）
- 项目汇总：各项目分类数量与物料金额汇总、总计及明细

数据保存在浏览器 localStorage（`lawn3d.state.v1`）。

## 边界文件格式

```json
[[20, 7], [14, 13], [-14, 13], [-20, -7]]
```
或 `{ "boundary": [[x, z], ...] }`，或 GeoJSON Polygon Feature。单位为米。
