# 地形浮雕分块下料建模工具

地质公园科普展馆地形浮雕的建模与分块下料工具。React 18 + WebGL2（无第三方几何/3D 库，几何算法全部自研）。

## 功能与工作流

| 阶段 | 能力 |
|---|---|
| 数据导入 | 高程点 CSV（x,y,z）、等高线折线 CSV（编号,x,y,z，自动沿线补点）、GeoJSON（Point/LineString/FeatureCollection，读 z 或 elevation）；IDW 反距离加权拟合为 97×97 地形高度场；内置程序化示例地形可直接体验 |
| 曲面雕刻 | Catmull-Rom 样条 + 控制点拖拽，山脊（抬升）/沟谷（下切）可调幅度与影响半径，沿样条高斯叠加 |
| 可视化 | WebGL2 三种着色：高程分层、曲率配色（蓝=凹/沟谷，红=凸/山脊）、坡度分级（0–15°/15–25°/25–35°/>35°）；HUD 实时显示光标处坐标、高程、坡度，超限坡度红色提示 |
| 浮雕厚度 | 圈选雕刻范围 → 沿外轮廓等距内偏移（斜接限值），偏移过头产生自交时 3D/2D 双视图红色标记并提示 |
| 曲面摊平 | 每块以格网弹簧模型松弛摊平（三维表面棱边为弹簧原长），输出摊平轮廓、最大/平均边长失真率 |
| 分块下料 | X/Y 向块数与每条分缝格线位置均可手动调整；下料图标注每段边长、拼缝编号、拼缝两侧块号对应关系与高差，附图签（外包尺寸、均高、失真率、拼缝对应） |
| 拼缝分析 | 拼缝表：平面长、公共表面长、两侧摊平下料长、最大/平均跨缝高差、块间平均高差 |
| 批次复核 | 提交后自动检查，按**严重 / 提醒**两级列出；复核员逐条「确认（退回重做）」或「驳回（误报）」，支持批量处理；全部复核完成且无确认项才允许整批放行 |
| 导出 | 放行后导出 ZIP：每块带编号 SVG 下料图（mm 单位、含图签）、拼版总图、物料清单 CSV、拼缝对应表 CSV（自研 store 模式 ZIP，无需依赖） |

### 自动检查项

- **严重**：外轮廓未闭合、分块单元重叠、摊平尺寸超板材幅面、偏移轮廓退化
- **提醒**：偏移自交、摊平失真 >3%、拼缝两侧下料长偏差 >5%、块内最大坡度 >40°


## 关键算法说明

- **IDW 拟合**：空间哈希分桶 + 环形扩张取最近 12 点，距离平方反比加权，格网规模下线性于格点数。
- **等距偏移自交**：逐边按内法线平移后斜接求交，再做全边对线段求交；同时用面积绕序翻转识别"偏过头"的退化轮廓。
- **摊平**：质量-弹簧 Gauss-Seidel 松弛，固定边界环上最远两顶点消除刚体自由度，弹簧原长取含高差的三维棱边长；失真率 = |摊平边长−表面边长|/表面边长。
- **拼缝编号**：相邻异块单元边按并查集连通性聚合成缝，双向写入两块的分段，保证两侧对应关系可追溯。
- **单位约定**：建模坐标单位为米，SVG/CSV 下料尺寸统一换算为毫米。
