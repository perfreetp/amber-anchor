# 古生物复原 · 骨架绑定与步态动画编辑器

自然博物馆古生物复原组内部工具。React 18 + WebGPU,纯静态站点,无需构建。

## 运行

需要支持 WebGPU 的浏览器(Chrome / Edge 113+)。

```bash
# 任意静态服务器,例如:
cd paleo-editor
npx serve .          # 或 python -m http.server
```

直接双击 `index.html` 也可以运行(所有依赖已本地化到 `lib/`)。

打开后首页按展厅分卷列出项目与解算帧数;首次运行自带「古脊椎动物展厅 / 霸王龙步态复原」演示项目。

## 功能对照

| 需求 | 位置 |
|---|---|
| 化石扫描件分件导入(颅骨/颈椎/肩胛/肱骨/股骨) | 左栏「化石部件」:模板部件 + `.obj` 导入 |
| 部件树拖动建父子层级、调整关节枢轴 | 左栏「骨骼层级」拖拽;「关节」面板改枢轴 |
| 关节角度限位(防膝盖反折) | 「关节」面板,含膝关节防反折预设 |
| 笔刷涂蒙皮权重 | 视口「蒙皮」模式 + 右栏「蒙皮」页(半径/强度/减去) |
| 未归一化顶点实时标红 | 蒙皮模式下自动标红,面板显示坏顶点数,可一键归一化 |
| 24 帧关键帧、位移/旋转/缩放三通道 | 底部时间轴(双击打帧、拖动移帧、右键删除)+ 右栏「通道」 |
| 曲线编辑器贝塞尔手柄缓动 | 「通道」页下方曲线编辑器,拖黄色关键点与蓝色手柄 |
| 前腿步态复制到后腿并偏移 12 帧 | 「步态」页:生成 24 帧步行循环 → 选源骨/目标骨 → 复制 +12 |
| 播放实时预览 | 视口工具栏 ▶,24fps 循环 |
| 摄像机环绕 / 正交切换 | 视口拖动环绕、滚轮缩放、Shift 拖动平移;「透视/正交」按钮 |
| 骨面粗糙度与主光角度(展厅筒灯) | 「材质」页 |
| 导出 PNG 序列帧 | 顶栏「导出 PNG 序列」(打包 zip,1280×720) |
| 导出带骨骼层级的 glTF | 顶栏「导出 glTF」(.glb,含 skin、逆绑定矩阵、烘焙动画) |
| 项目按展厅分卷存浏览器本地 | localStorage,首页按展厅分组 |
| 复原组提交版本 | 「版本」页「提交版本」(快照骨骼/轨道/蒙皮/材质) |
| 策展人画面+时间轴打点批注 | 「批注」页新建 → 视口点击放置标记;时间轴标尺显示 📌 |
| 制作方逐条回复处理 | 批注列表内回复、「已处理」开关 |
| 版本左右对比 | 「版本」页选 A/B →「左右对比」,同一帧滑杆联动 |
| 首页列各展厅项目和解算帧数 | 首页项目卡片 |

## 深链与自检

- `#open` 或 `#open=<项目id>`:直接打开项目
- `#selftest`:脚本化自检(步态/版本/批注/蒙皮/离屏导出),结果在控制台
- `#selftest-compare`:分屏渲染像素断言

## 测试

```bash
node test/smoke.js   # 核心逻辑冒烟测试(骨骼求值/曲线/蒙皮/限位/步态/版本)
```

## 结构

```
index.html      入口
css/app.css     样式
js/math.js      mat4/quat/vec3
js/meshes.js    程序化骨骼部件 + OBJ 解析
js/core.js      数据模型、骨骼求值、曲线、蒙皮、步态、项目存储
js/renderer.js  WebGPU 渲染(GPU 蒙皮/骨骼线框/权重着色/离屏导出)
js/exporters.js PNG 序列(zip)+ glTF(.glb)导出
js/ui.js        React 界面(htm,无构建)
lib/            本地化的 react / react-dom / htm
test/smoke.js   Node 冒烟测试
```
